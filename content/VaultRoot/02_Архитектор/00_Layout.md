# ⚙️ System Architect Layout

## 🧠 Рабочие панели

| Панель | Назначение | Плагины |
|--------|-------------|----------|
| 🗂️ **Project Manager** | Навигация по активным проектам | Quick Switcher, Dataview |
| 💬 **Brain Flow** | Свободное мышление, поток идей | Canvas, Excalidraw |
| 🧭 **Dashboard** | Центр управления системой | Minimal Theme, Buttons |
| 📊 **System Monitor** | Финансы + метрики сервера | DataviewJS, Charts |
| 🧘 **PsyCore** | Психологические заметки, рефлексия | Periodic Notes, Tracker |

---

## ⚡ Горячие клавиши

| Действие | Shortcut |
|-----------|-----------|
| Открыть Dashboard | `Ctrl + Shift + D` |
| Новый проект | `Ctrl + Shift + P` |
| Рефлексия дня | `Ctrl + Shift + R` |
| Поиск по системе | `Ctrl + O` |
| Тоггл-тема (день/ночь) | `Ctrl + Shift + T` |

---

## 🎨 Рекомендуемые темы

- 🖤 **Minimal** (главная, для чистого интерфейса)
- 💡 **ITS Theme** (для более системного, tech-стиля)
- 🌈 **Blue Topaz** (если хочешь сделать Control Center визуально “живым”)

---

## 💎 Плагины для “режима архитектора”

| Плагин | Назначение |
|--------|-------------|
| **Dataview** | Таблицы, списки проектов и целей |
| **Canvas** | Визуальные связи и карты мышления |
| **Buttons** | Добавление интерактивных кнопок на Dashboard |
| **Tracker** | Отслеживание привычек, прогресса и метрик |
| **Templater** | Шаблоны для заметок, автоматизация |
| **QuickAdd** | Быстрое создание задач и записей |
| **Periodic Notes** | Дневники, недели, месяцы |
| **Charts** | Визуализация данных (финансы, статистика) |
| **Style Settings** | Тонкая настройка интерфейса |
| **Advanced Tables** | Красивые таблицы без боли |
| **DataviewJS** | Скриптовые дашборды внутри Obsidian |

## 🧩 Дополнительно
